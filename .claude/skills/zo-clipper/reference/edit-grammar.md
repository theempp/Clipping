# Edit grammar (options, not defaults)
Sources: Kenji guide (Nate Herk), Clipper free `clips.md`, our `Reference Clip Style.md`. Zo's locked decisions win: D048/D050/D073 captions, D052 SFX off, D077 zooms (no robotic moves).

| Element | Kenji | Clipper | Ours now | Proposal |
|---|---|---|---|---|
| Length | 12-20 s (12-16 best) | 15-45 s | 10-60 s QA | 12-25 s default; longer only for a chain of escalations |
| Layout | stack, cam top | stack / fit / crop / auto | per-streamer boxes | keep stack; `fit` when whole screen matters (map, wide crash) |
| Hook | payoff-first teaser 2-4 s + white flash + whoosh | 2-7 word sticker card, 1 starred word, 2.8 s | static headline (Style A) | A/B: headline vs teaser (see experiments); flash/whoosh stays OFF unless Zo opts in (D052) |
| Hook text | context, never "STREAMER DOES X" | tension/question/promise, never fake quote | headline formula in Reference Clip Style | keep our formula; add banned pattern + search keyword in frame 1 |
| Payoff | 70-85% of runtime, slow-mo/freeze 0.35-0.5x for 0.5-1 s | cut right after payoff | zoom only | allow ONE freeze/slow-mo on the funniest frame; zoom stays eased per D077 |
| Reaction hold | 0.5-1.5 s on facecam, real laugh audible, no music | end after reaction | none | end on reaction peak; hold 0.5-1.5 s |
| End | hard cut that loops into teaser | cut after payoff | natural | A/B loop-end only if teaser style wins |
| Captions | subtitles (hand-timed) | 3-word Montserrat caps, yellow active | A static / B word pop | unchanged (D073 test) |
| Credit | on screen + caption | n/a | per campaign rules | always in caption; on-screen if campaign requires |

## Text rules to adopt
Text adds context. One text style. Never over the face. No emoji in burned text. Keep punchline out of the teaser window so two blocks never stack. Never guess words: if unclear, don't subtitle; read in-game captions so an NPC line is never put in the streamer's mouth.

## Layout traps (from Kenji's mistakes list)
Crop facecam inside its border; crop gameplay to exclude chat, burned captions, watermarks. Watch live-caption bars, green-screen cams, letterbox on cinematic crashes. Ending on a loading screen after WASTED: freeze the WASTED frame. Smoke/fog payoffs read as white in a teaser: tease the frame before impact. Whole-frame zoom breaks stack layouts: zoom the facecam panel only.

## Platform notes
- TikTok Creator Rewards (>= 1 min) rejects bare/split-screen reposts (D080): this grammar is for X / Shorts clips only.
- Instagram: subtitles + credit do not count as original; unique on-screen text can (Kenji guide, UNVERIFIED by us).
