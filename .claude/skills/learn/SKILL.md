# Learn
1. Log to `Learning and Memory.md`: skill affected, evidence (clip/campaign ID, metric), proposed rule, success check.
2. One-off preference stays in the project record. Only a reproducible failure or 2+ corroborating cases becomes a rule.
3. Make the smallest edit; keep prior text in git. Test: normal request, the fixed failure, a lookalike that should not trigger.
4. Promote if supported, keep as proposal if unsure, revert on regression. No lesson? Skip, move on.
5. Keep each skill under ~60 lines; if a rule grows, move detail to a reference file loaded on demand.
